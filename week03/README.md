# 3주차 - 셸 스크립팅

## 이번 주에 한 일
Ollama로 작은 AI 모델(qwen3:0.6b)을 내 컴퓨터에 띄우고, 파이썬 웹 앱(chat.py)을 실행하는 과정을 셸 스크립트로 자동화했다.

## 왜 셸 스크립트인가
반복 작업을 손으로 하면 시간도 들고 오타나 순서 실수가 생긴다. 스크립트로 적어 두면 몇 번을 실행해도 똑같이 동작한다.

## 구조
브라우저(localhost:8000) → chat.py(파이썬 웹 앱) → Ollama 서버(127.0.0.1:11434) → qwen3:0.6b 모델

- Ollama는 모델을 실행하고 관리하는 서버, Qwen은 답변을 만드는 모델이다.
- 모델은 Ollama가 따로 보관하니 레포에 복사하거나 push하지 않는다.

[여기에 캡처: `ollama list`, 브라우저에서 질문과 답변 화면]

## start.sh 만들기
```bash
#!/bin/bash
cd "$(dirname "$0")" || exit 1
exec python3 chat.py
```

| 줄 | 하는 일 |
|---|---|
| `#!/bin/bash` | shebang. 이 파일을 Bash로 실행하라고 OS에 알려줌 |
| `cd "$(dirname "$0")"` | 스크립트가 있는 폴더로 이동. 어디서 호출해도 같은 위치 기준으로 동작 |
| `\|\| exit 1` | 앞 명령이 실패하면 실패 코드 1로 종료 |
| `exec python3 chat.py` | 현재 bash를 python3로 교체해서 실행 |

- `$( )`는 안의 명령 결과를 그 자리에 넣는 명령어 치환이다.
- 명령의 종료 상태는 0이 성공, 0이 아니면 실패다. 숫자 0이 거짓인 프로그래밍 언어와 반대라 헷갈렸다.

## 실행 권한 문제
처음 `./start.sh`를 실행하면 `Permission denied`가 나온다. `ls -l`로 보면 실행(x) 권한이 없어서이고, `chmod u+x start.sh`로 해결했다. 그냥 `start.sh`로 실행이 안 되는 건 PATH에 없는 파일이라서 `./`를 붙여야 한다.

[여기에 캡처: Permission denied 후 chmod로 해결한 화면]

## 환경 변수와 조건문
```bash
#!/bin/bash
cd "$(dirname "$0")" || exit 1
export MODEL="qwen3:0.6b"   # 이 스크립트 안에서만 적용됨
exec ./start.sh
```
- 같은 방식으로 `WEB_PORT="8080"`을 주면 포트를 바꿔서 실행할 수 있다.
- python3가 설치되어 있는지 검사하는 조건문도 배웠다.
```bash
if ! command -v python3 >/dev/null 2>&1; then
  echo "Python3를 먼저 설치하세요." >&2
  exit 1
fi
```
`>/dev/null`은 출력을 버리는 것이고, `2>&1`은 오류 출력도 같은 곳으로 보내는 것, `>&2`는 메시지를 오류 출력으로 보내는 것이다. 메시지를 오류로 보내는 것과 실패 코드로 종료하는 것은 별개라서 `exit 1`을 따로 적는다.
